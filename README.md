# ⚡ IDEATION '26 — IETE Web App

Official website for **IDEATION '26** (National Level Idea Presentation Competition organized by the **IETE Student Forum**).

---

## ⚡ Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server (http://localhost:3000)
npm run dev

# 3. Build for production
npm run build
```

---

## 📝 Updating Event Details

All dates, prizes, Google Form link, rules, FAQs, and contacts are updated in **a single file**:

📍 **`src/config/eventConfig.js`**

Simply edit values in `eventConfig.js` when the committee head provides the final details — all changes reflect automatically across the website!
